questions

Switching is easy

How is Zellij different from tmux?

Zellij shows its keys on screen, and more comes built in: layouts, restoring sessions after a reboot, a web client, its own terminal window and the agent inbox. It also runs natively on Windows. If your fingers know tmux, press Ctrl b: tmux mode keeps " and % to split, and c for a new tab.{{ with $vsTmux }} Zellij vs tmux, side by side →{{ end }}

Which coding agents does it work with?

Any agent that runs in a terminal. Codex CLI, Claude Code, OpenCode, Pi, goose and others report their status to the inbox on their own. For the rest, Zellij picks up bells, desktop notifications and prompt markers. Full list

Do I have to give up my terminal?

No. Zellij runs inside the terminal you already use. Since 0.46 it can also run in its own window with zellij terminal, which adds a tray icon and desktop notifications.

Can I use it on a server, or from my phone?

Yes. Run it on a remote machine over SSH and your sessions survive dropped connections. The built-in web client opens your sessions in a browser, including on a phone.

Is Zellij free?

Yes. It's free and open source under the MIT license, with no ads, no telemetry and no account. The maintainers also run zellij.online, an optional paid service for sharing sessions.

Who makes Zellij?

Aram Drevekenin works on it full-time, funded by sponsors, with a handful of volunteers who help in different areas. The first beta shipped in April 2021, and a new release has followed every few months since.
